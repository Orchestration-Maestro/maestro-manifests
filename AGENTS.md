# Working in maestro-manifests

## Before anything else

Read [README.md](README.md) for the owner-first catalog's layout and
segregation rules. This repository holds public manifests for agents, skills,
instructions, MCP servers and presets.

## Rules that bind every change

- No private or vendor content belongs here. Private collections plug in from
  outside this public repository.
- Managed files are generated by `rust-gate`; do not hand-edit them. Run
  `rust-gate sync`, `rust-gate rules` and `rust-gate guide` to regenerate them.
- Keep changes scoped to the request and report the checks actually run.
- Commits are conventional and signed. Propose changes through a pull request;
  do not push directly to `main`.
